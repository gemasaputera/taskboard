Kanban for small teams · MIT licensed

A kanban board for small teams that stays in sync

Kanban is a free, open-source task board for teams of 2–10 people. Every account gets a workplace with four lanes — To Do, Revision, On Progress, and Done — where cards carry Markdown descriptions, checklists, colored tags, assignees, and comments. Socket.IO keeps every board in sync, and an MCP server lets AI agents work the same cards.

Features

Everything a small team needs on one board

Kanban covers the work without adding another tool to administer: structure the owner controls, cards that hold the whole task, and live updates for everyone in the workplace.

Four lanes, shaped by the owner

Every workplace starts with To Do, Revision, On Progress, and Done. Owners rename, reorder, hide, add, and delete lanes; deleting a lane moves its cards to the first visible remaining lane instead of destroying them.

Cards that hold the whole task

Write the description in Markdown with a Write/Preview editor, then break it into checklist subtasks with progress, add multiple colored tags and assignees, and keep the conversation in a threaded comment list.

Drag and drop on any input

Move cards with a mouse, a finger, or the keyboard through dnd-kit. Updates are optimistic, the server owns the final ordering, and a card's position survives a reload.

Live for everyone

Socket.IO pushes changes to every open board in the workplace. If a client drops its connection, it refetches on reconnect and on window focus so nobody works from stale lanes.

Invitations and clear roles

The owner invites an already-registered teammate by exact username or email; the invitee accepts or declines in the app. Owners manage structure, members, and tags — members move and discuss work.

A board AI can work on

An MCP server exposes the board as 39 tools over stdio or 36 over Streamable HTTP with OAuth. Claude, Cursor, Codex, or Hermes Agent can create, move, and update work without opening a browser.

How it works

From sign-up to a moving board in three steps

There is no setup wizard and no empty workspace to configure. Register, shape the lanes to match how your team works, then move the first card.

  1. 01

    Register an account

    Usernames and emails are checked live against the database, and a strength meter enforces a 8+ character password with mixed case, a number, and a symbol. Your workplace and four lanes are created immediately.

  2. 02

    Shape the board and invite the team

    Rename or reorder the lanes, hide the ones you do not use, and add lanes for your process. Invite teammates by username or email; they accept from the bell and appear on the board right away.

  3. 03

    Move work forward

    Add a card, describe it in Markdown, break it into checklist items, tag and assign it, then drag it across lanes. Everyone sees the move live, and AI clients can work the same cards through the MCP server.

AI & MCP

Can AI agents work on your board?

Yes. Kanban ships an MCP server that exposes the board as 39 tools over stdio, or 36 tools over Streamable HTTP with OAuth. Claude, Cursor, Codex, Hermes Agent, or any MCP client can read boards and create, move, and update cards, checklists, comments, tags, assignees, columns, members, and invitations.

The MCP server drives the same REST API as the web app, so permissions, ordering, and realtime updates behave identically. A card moved by an agent appears live in every open browser.

Self-hosting

Self-host it in one container

Kanban is MIT-licensed and ships a Dockerfile that builds the web app and API, applies database migrations, and starts the server. You need PostgreSQL and three environment variables: DATABASE_URL, JWT_SECRET, and CLIENT_ORIGIN.

  • Node 22+ and PostgreSQL (Neon or a local Docker Postgres)
  • Works on Render, Railway, Fly.io, a VPS, or a single Docker host
  • Scrypt password hashing, httpOnly 7-day sessions, helmet CSP, and rate limits on auth

Deployment guide ↗

Run the published image

docker build -t kanban-board .

docker run -d --name kanban -p 4000:4000 \
  -e DATABASE_URL="postgresql://...pooler..." \
  -e DATABASE_URL_UNPOOLED="postgresql://..." \
  -e JWT_SECRET="<32+ random characters>" \
  -e CLIENT_ORIGIN="https://your-domain.example" \
  kanban-board

Then point a reverse proxy at port 4000 for TLS.

FAQ

Questions teams ask before switching

Short, direct answers about cost, AI access, comparisons, team size, and hosting.

What is Kanban?

Kanban is a free, open-source task board for small teams. It gives each account a workplace with four lanes — To Do, Revision, On Progress, Done — and cards that carry Markdown descriptions, checklists, tags, assignees, and comments. It is built for teams of 2–10 people, not enterprise portfolio management.

Is Kanban free to use?

Yes. The source code is MIT-licensed, so self-hosting carries no license fee. The hosted instance is free to sign up for. You provide your own PostgreSQL database if you self-host.

Can AI assistants use the board?

Yes. An MCP server exposes the board as 39 tools over stdio or 36 tools over Streamable HTTP with OAuth. Claude, Cursor, Codex, Hermes Agent, or any MCP client can read boards, create and move cards, manage checklists, comments, tags, assignees, columns, members, and invitations. Changes appear live in the web app.

How is Kanban different from Trello?

Kanban is purpose-built for small teams: one workplace with four default lanes instead of a general-purpose board builder, owner-controlled structure, in-app invitations, and an MCP server that lets AI agents work the same board as people. It is MIT-licensed and self-hostable.

How many people can join a workplace?

Kanban is designed for teams of 2–10 people. The owner invites an already-registered user by exact username or email, and the invitee accepts or declines in the app. Owners manage structure, invitations, members, and tags; members work on cards.

Do I need to self-host Kanban?

No. A hosted instance is available at kanban-board-p4kk.onrender.com. Self-hosting is optional and supported through Docker, Render, Railway, Fly.io, or any Node 22+ host with PostgreSQL.

Does drag and drop work on mobile and with a keyboard?

Yes. Cards move with mouse, touch, and keyboard through dnd-kit. The card dialog also includes a Move to… menu for a non-drag path, and every control has a visible focus ring.

Is realtime collaboration included?

Yes. Socket.IO keeps every member's board in sync. Drag changes are applied optimistically, committed by the server, and rolled back with a toast if the request fails. Reconnecting clients refetch on reconnect and on window focus.
